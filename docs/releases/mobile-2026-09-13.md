## Vérifications et utilisation

TypeScript, lint des fichiers modifiés et 20 tests passent. Le workflow Expo a
également exécuté TypeScript et les tests avant publication. La configuration
OTA a été vérifiée dans l’IPA final, puis comparée au manifeste réellement servi.

Installer d’abord le build 41 depuis TestFlight, puis ouvrir **Profil → Mises à
jour** pour rechercher, télécharger et appliquer les corrections. Les mises à
jour suivantes compatibles avec ce runtime n’exigent pas de nouvelle compilation.
Un changement natif nécessite toujours un nouveau build.

La recherche, le téléchargement et le redémarrage n’ont pas été exécutés sur
l’iPhone de l’utilisateur pendant cette livraison ; cette vérification sur appareil
reste à faire après installation du build TestFlight.
