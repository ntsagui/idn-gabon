# Livraison SSO Identité.ga du 13 septembre 2026

## Correctif livré

Le portail reprend une session Identité.ga existante pendant une connexion OIDC,
avec conservation de state, nonce, PKCE, prompt et max_age. Une demande explicite
de réauthentification reste respectée. Après identification et PIN, le parcours
reprend l'autorisation du client au lieu de perdre son contexte.

Le proxy web transforme les redirections HTTP du fournisseur en réponse JSON
pour les requêtes fetch et conserve la redirection HTTP des navigations. Le
plugin backend crossDomain passe après oidcProvider afin que son traitement de
Set-Cookie ne masque pas la nouvelle session au hook de réauthentification OIDC.
